# GAS同期をGoogleドライブ保存版に切り替える手順

対象: `gas-sync-drive-backend.gs`（2026-10-28 追加）

## 何が変わるか

| 項目 | 旧GAS（プロパティ保存） | ドライブ保存版 |
|---|---|---|
| 保存先 | スクリプトプロパティ（全体で約500KBが上限） | ドライブ「ぺいとり同期/patient-triage-data.json」（実質上限なし） |
| 上書き | 最後に送った端末が丸ごと上書き | 版番号で確認。別端末が先に更新していたら上書きせず「同期の確認」を出す |
| 控え | なし | 1時間ごとの控えを「ぺいとり同期/控え」に30日分。強制上書き前の内容も残す |
| 送信失敗 | 次の変更まで送られない | 「未送信」を表示し、10秒〜10分の間隔で自動再送。画面を離れるときにも送る |
| 送る内容 | 容量対策でログを間引いて送信 | 間引かずに全部送る |
| 症例メモ | なし | Markdownで「症例メモ」フォルダへ書き出せる |

アプリ側は旧GASのままでも今までどおり動きます。GASを入れ替えた時点で、上の新しい動きに切り替わります。

## 手順（10分ほど）

1. **念のためバックアップを取る**
   アプリの「データ > バックアップ」でJSONを書き出しておく。

2. **新しいファイルを追加する**
   Apps Script エディタで「ファイル +」> スクリプト。名前を `gas-sync-drive-backend` にして、
   リポジトリの `gas-sync-drive-backend.gs` の中身をすべて貼り付ける。

3. **旧本体の doGet / doPost を消す**
   旧本体のファイルにある `function doGet(e) {...}` と `function doPost(e) {...}` を削除する。
   同じ名前の関数が2つあると、どちらが動くか分からなくなるため。
   - `gas-chunked-storage.gs`（分割保存）は消さずに残す。旧データの引き継ぎに使う
   - ntfy などのアドオンのファイルも残してよい

4. **シークレットを登録する**
   「プロジェクトの設定」>「スクリプト プロパティ」に次を追加する。
   - `SYNC_SECRET` = アプリの「GAS設定」に入れているシークレットと同じ文字列
   旧本体の `const SECRET = '...'` を残している場合は省略できる。

5. **ドライブの権限を許可する**
   エディタ上部の関数選択で `syncSetupDrive` を選んで「実行」。
   権限の確認が出るので許可する。実行ログに「同期フォルダ」のURLが出れば成功。
   この時点で旧データがドライブへ版1として引き継がれ、「控え」に `patient-triage-legacy-properties.json` が残る。

6. **同じURLのまま公開し直す**
   「デプロイ」>「デプロイを管理」> 鉛筆アイコン >「バージョン: 新バージョン」>「デプロイ」。
   「新しいデプロイ」ではなく既存デプロイの編集にすると、アプリ側のURLを変えずに済む。

7. **各端末でアプリを開く**
   最初に開いた端末ごとに1回だけ「同期の確認」が出る。
   - いちばん新しい内容を持っている端末では「この端末の内容でGASを上書き」
   - それ以外の端末では「GASの内容を読み込む」
   どちらを選んでも、選ばなかった側の内容は控え（ドライブ）か端末内バックアップに残る。

## Obsidian 用の設定（あとからでよい）

vault を Google ドライブへ移したら:

1. Google ドライブ（デスクトップ版）の同期方式を「ミラーリング」にする
   （「ストリーミング」だと Obsidian が遅くなりやすい）
2. vault の中に症例メモ用のフォルダ（例: `症例メモ`）を作る
3. そのフォルダをブラウザのドライブで開き、URLの `folders/` の後ろの文字列（フォルダID）をコピーする
4. スクリプト プロパティに `CASE_MEMO_FOLDER_ID` = フォルダID を追加する（再デプロイは不要）

設定するまでは「ぺいとり同期/症例メモ」に書き出され、後から vault へ移せる。

## 困ったとき

- **「シークレットが一致しません」**: 手順4の `SYNC_SECRET` とアプリのシークレットが同じか確認する
- **「GASにSYNC_SECRETが設定されていません」**: 手順4を行う
- **上書きしてしまった内容を戻したい**: ドライブの「ぺいとり同期/控え」から該当時刻のJSONを開き、
  中身をアプリの「データ > インポート」に貼り付ける
- **元に戻したい**: 新しいファイルを削除し、旧本体の doGet / doPost を戻して再デプロイする。
  旧データ（スクリプトプロパティ）は消していないのでそのまま使える。
  ただし切り替え後にドライブへ保存した変更は旧データに入っていないので、先にバックアップを書き出しておく
