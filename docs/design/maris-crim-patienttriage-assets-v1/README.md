# マリス＆クリム PatientTriage キャラパック v1

ムーンブルク王女マリスとサマルトリア王子クリムを、常に二人一組で表示するナビキャラパックです。

- ID: `maris_crim`
- 表示名: マリス＆クリム
- アプリ画像: 320×448 px / 透過PNG / 中心X=160 / 接地Y=424
- 構成: 通常立ちを含む9ポーズ
- セリフ: ぺいとり160本、でいとり30本、わーとり10本（合計200本）
- 通知: 時報・予定・昼食・おやつ・寄り道用の掛け合い18本
- 表示: 名前を視覚表示しない二段吹き出し

## フォルダ

- `app_320x448/`: アプリ投入用9枚
- `tight/`: 透過余白を除いた原寸クロップ
- `maris_crim_runtime_preview.png`: 9ポーズ一覧
- `coach-library.js`: キャラ設定・画像対応・全セリフ
- `generation-prompt.md`: 再生成時の基準プロンプト
- `manifest.json`: ファイル対応と寸法・表示倍率

## デザイン要点

マリスは長い紫の巻き髪、紋章と赤い宝石の付いたマゼンタ色の帽子、同色の肩掛け、赤い縁取りの白いローブ、マゼンタ色のブーツです。礼儀正しく落ち着いていますが、仰々しくない自然な表情と身振りにしています。

クリムは大きく逆立つ橙色の髪、ゴーグル付きの緑と茶色の飛行帽、黒いインナー、紋章入りの緑の上衣、緑の手袋とブーツ、橙色のマントです。実力者らしい身のこなしを保ちつつ、早合点や遠回りが表情へ少し出ます。

小画面で崩れやすい杖・剣・盾は全ポーズで省いています。立ちポーズは足元を揃え、座りポーズはポーズ別倍率で顔と頭身の見かけサイズを補正します。
