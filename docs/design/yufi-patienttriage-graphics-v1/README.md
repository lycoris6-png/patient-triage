# ユーフィ — PatientTriage グラフィック v1

DQ3女勇者ユーフィの画像9種。少し引っ込み思案で健気な表情・小さな身振りを軸にした。
頭の大きさと身体の短さは、現行エスト赤の実画像を参考にしている。

## 内容

- `app_320x448/`: 実アルファ透過PNG9種。共通キャンバス320×448px、足元基準y=424。
- `tight/`: 各ポーズの余白を詰めた透過PNG9種。外側に4pxの透明余白。
- `master/`: 生成した基準立ち、生成元シート、固定3×3グリッドへ整理した透過シート。
- `preview/contact-sheet-app.png`: 確認用のラベル付き一覧。
- `preview/runtime-96px-preview.png`: エストとユーフィ9種を高さ96pxで並べた比較。
- `manifest.json`: 各PNGの寸法・非透明範囲・接地点などの機械検査結果。
- `generation-prompts.md`: 使用した生成プロンプト一式。

| 番号 | 動作 | ニズッチ |
| --- | --- | --- |
| 01 | 手を腰元で合わせた基準立ち | — |

ニズッチは添付参考の赤黒い丸い身体・黄色い目と中央の縦長の印・赤い腹部・長く曲がる腕を簡略化し、勇者の銀のサークレットと緑の宝石を付けた。
剣・盾・鞘は省略した。

ファイル名のthumbsup/laptop/smug等は既存9種との互換用。実際のポーズは上表を参照。
全ポーズを共通倍率で配置し、座り姿も頭と身体の縮尺を維持する。
生成元シートのセル間隔は均等ではなかったため、互いに接していない9つの非透明領域を検出して切り分けた。納品シートは320×448pxの固定3×3グリッドへ再配置している。
通常立ちの描画高は約379px。高さだけを400pxに揃えるのではなく、エストと並べた頭の見かけサイズと、ニズッチを含む安全余白を優先した。
初回のグラフィックZIPは画像のみ。2026-10-29に正本へキャラ登録し、短い仮文を追加した。正式なセリフへの差し替えは同フォルダの `dialogue-handoff.md` と `yufi-character-package.placeholder.json` を参照。
