# シン＆リリカ PatientTriage キャラパック v1

ローレシア王子シンとサマルトリア王女リリカを、常に二人一組で表示するナビキャラパックです。

- ID: `shin_lilika`
- 表示名: シン＆リリカ
- アプリ画像: 320×448 px / 透過PNG / 中心X=160 / 接地Y=424
- 構成: 通常立ちを含む9ポーズ
- セリフ: ぺいとり160本、でいとり30本、わーとり10本（合計200本）
- 表示: シンの無言の身振りとリリカの発話を、名前を視覚表示しない二段吹き出しで表示

## フォルダ

- `app_320x448/`: アプリ投入用9枚
- `tight/`: 透過余白を除いた原寸クロップ
- `shin_lilika_runtime_preview.png`: 9ポーズ一覧
- `coach-library.js`: キャラ設定・画像対応・全セリフ
- `generation-prompt.md`: 再生成時の基準プロンプト
- `manifest.json`: ファイル対応と寸法・表示倍率

## デザイン要点

シンは16歳。青い飛行帽型の兜とゴーグル、青い上衣、黒いインナー、青い手袋と靴、白い脚絆です。口を閉じた生真面目な表情を基本とし、発話はせず、視線・うなずき・小さな手振りだけで意思を示します。

リリカは13歳。橙色の巻き髪を大きな白いリボンで結び、黄色いチュニック、緑のマント、灰色のタイツ、茶色のブーツを着用します。やんちゃで明るく、年上の従兄シンを「シン兄」と呼んで慕い、無言の意図を自然に読み取ります。

小画面で崩れやすい剣・盾・杖は全ポーズで省いています。立ちポーズは足元を揃え、座りポーズはポーズ別倍率で顔と頭身の見かけサイズを補正します。
