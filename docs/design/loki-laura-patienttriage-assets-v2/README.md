# ロキ＆ローラ PatientTriage キャラパック v2

DQ1ロキとローラ姫を、常に二人一組で表示するナビキャラパックです。

- ID: `loki_laura`
- 表示名: ロキ＆ローラ
- アプリ画像: 320×448 px / 透過PNG / 中心X=160 / 接地Y=424
- 構成: 通常立ちを含む9ポーズ
- セリフ: ぺいとり160本、でいとり30本、わーとり10本（合計200本）
- 表示: 二人の発話を、名前を視覚表示しない二段吹き出しで表示

## フォルダ

- `app_320x448/`: アプリ投入用9枚
- `tight/`: 透過余白を除いた原寸クロップ
- `loki_laura_runtime_preview.png`: 9ポーズ一覧
- `coach-library.js`: キャラ設定・画像対応・全セリフ
- `generation-prompt.md`: 再生成時の基準プロンプト
- `manifest.json`: ファイル対応と寸法基準

## デザイン要点

ロキは兜を外した黒髪、青い鎧、橙のインナー、赤いマント。前髪と頭頂部には跳ねを残し、長い後ろ髪は襟足の低い位置で細い紐により一つに結び、毛束は広がらずマント沿いに落ちます。ローラは橙色の長髪、青い宝石のティアラ、金色のドレス、白手袋、紫の帯です。小画面で崩れやすい剣・盾・兜は全ポーズで省いています。

ロキは丁寧だが機械的に「確認・判断・処理・順序」を述べ、ローラは姫君らしい気品と温かさで、ユーザー自身の選択と休息を補います。
